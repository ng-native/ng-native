When I started Angular Native, the goal was simple: let Angular developers build real native apps
without learning a second framework. Since then, hundreds of you have starred the repository, filed
issues, sent pull requests and shipped apps with it.

Today I'm happy to share that the project has a long-term home. **Coralogix now maintains Angular
Native**, and I'll keep leading it from there.

## What changes

Coralogix is committing engineering time to Angular Native for the long term. That's the real news
here: the project now has a team and a company behind it that want it to succeed for years to come.

If you're deciding whether to build on Angular Native, this is the reassurance you've been looking
for. It will be well maintained going forward, with predictable releases, quicker answers in issues
and discussions, and updates that keep pace as Angular, React Native and Expo move on. It also means
the time to take on larger pieces of work that a side project struggles to finish.

## What stays the same

- **The license.** Angular Native is MIT licensed, and that isn't changing.
- **The code and packages.** Same repository, same `@ng-native` packages on npm, no account or
  sign-up needed.
- **How we work.** Issues, discussions, pull requests and release notes stay public on GitHub, and
  decisions happen there.
- **The community.** Contributions from outside Coralogix are as welcome as ever, and reviewed the
  same way.

<figure class="blog-quote">

> Nothing about how you use Angular Native changes. What changes is how much time we can give
> it.

</figure>

## Why Coralogix

Coralogix builds its products with Angular. We want Angular developers to reach every platform with
the skills they already have, and looking after Angular Native is the most direct way to make that
happen.

## What's next

Desktop is the first big step. Angular Native apps now run on macOS and Linux, from the same
components you use on iOS and Android. The details are in the [desktop guide](/guide/desktop).

## Get involved

If you've built something with Angular Native, I'd love to see it. Star the repository, join the
discussions, or pick up a good first issue.
