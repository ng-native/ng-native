# Music

A small but real music player built with Angular Native: albums, a searchable song library, real
audio playback, and a mini player that docks above the tab bar and opens into a full-screen Now
Playing sheet.

| Screen                                                 | What it shows                                                                                                                |
| ------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| Library (`src/app/library/library.ts`)                 | Albums in a horizontal row, riding as a `<virtual-list>`'s `listHeader`, above every song, searchable from the native header |
| Album (`src/app/album/album.ts`)                       | Artwork, its tracks, and a "Play all" button - a pushed screen                                                               |
| Now playing (`src/app/now-playing/now-playing.ts`)     | Artwork, a real seek slider, play/pause/next/previous, shuffle and repeat - presented as a sheet                             |
| Mini player (`src/app/now-playing/mini-player-bar.ts`) | Docked above the tab bar on every other screen; opens Now Playing                                                            |
| Settings (`src/app/settings/settings.ts`)              | `ios:` and `android:` variants, the same pattern the wallet example's settings screen uses                                   |

The tab bar (`src/app/tabs.ts`) is a real `UITabBarController` on iOS and a bottom navigation bar on
Android. Playback itself is split into two services: `src/app/player/queue.ts` (track order -
next, previous, shuffle, repeat) and `src/app/player/playback.ts` (pointing a real player at
whatever the queue is on). `src/app/player/track-player.ts` is the seam between them: the
production path wraps `audioPlayer()` from `@ng-native/expo/audio`, and `app.test.ts` provides
a fake instead, since `expo-audio` is never installed under Vitest.

## Run it

From the repository root, after `pnpm install`:

```sh
cd examples/music
pnpm start     # press i or a, or scan the QR code with Expo Go
pnpm test      # Vitest in Node, no simulator
```

`src/app/app.test.ts` opens an album, plays it, skips a track and opens Now Playing, all against
the fake player. `src/app/player/queue.test.ts` drives the queue directly, with fake tracks
standing in for real audio, to check next, previous, shuffle and repeat in isolation.

## Assets

Every asset here is generated by this repository, not sourced from anywhere else, so there is
nothing to attribute or licence beyond the code itself:

- `assets/audio/*.m4a` - twelve short sine-wave tones, one per track, generated with `ffmpeg`
  (`assets/audio/generate.sh`). Each is two tones mixed together with a fade in and out, distinct
  enough to tell tracks apart while playing. About 820 KB in total.
- `assets/artwork/*.png` - four abstract radial gradients, one per album, generated with `ffmpeg`'s
  `gradients` filter, each in the album's own colour. About 320 KB in total.
- `assets/tab-*.png` - the two tab bar icons for Android, a note and a gear drawn from the Apple
  Symbols font with `ffmpeg`'s `drawtext` (`assets/generate-tabs.sh`). iOS uses SF Symbols instead
  (`music.note.list`, `gearshape.fill`), the same way the wallet example's tab bar does.

All assets together are a little over 1 MB, well inside the budget for an example that ships its
own media.
