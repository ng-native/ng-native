# A reader for Markdown files

Every note here is a `.md` file in `src/notes`. Metro parses its **front matter** and lexes its
_Markdown_ as it bundles the app, so the device draws tokens and parses nothing.

- Read [the formatting tour](/notes/formatting) for every element `<markdown>` draws
- Write a document of your own in [the live editor](/editor)
- See [a note styled with classes](/styled)

A link to another site, such as [Angular](https://angular.dev), opens outside the app.
