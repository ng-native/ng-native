# An evening edition

This note is drawn with `classes`, which swaps an element's default `md-*` class for one of the
app's own, from a global stylesheet.

## Headings and paragraphs

Headings take a serif face and a warmer color. A [link](/notes/welcome) keeps its default class
beside the new one, so it stays underlined and only turns bold.

> A quote here is a card rather than a rule down the side.

Inline `code` keeps its monospace face from the default class.
