# Taffy's layout fixtures

`block`, `blockflex`, `grid`, `blockgrid` and `gridflex` from [Taffy](https://github.com/DioxusLabs/taffy)'s `test_fixtures`, at
commit `04965fc`, unmodified, under Taffy's MIT licence (`LICENSE`). `ahem.css` is the Ahem
`@font-face` from its `scripts/gentest/test_base_style.css`.

Only the markup is used. Each fixture's expected layout is recorded from Chrome under this
project's own defaults by `scripts/record-oracle.mjs`, not taken from Taffy.
