A `background-size`, `background-position` or `background-repeat` set on an element now draws, a `background` set on an element takes a position, size, repeat and a colour beside its last gradient, `background: var()` puts a weaker rule's size, position and repeat back at their initial values, and on macOS `-webkit-font-smoothing` reaches text inputs and search fields and takes a token, `inherit`, `initial` and `unset`.

A `background-size`, `background-position` or `background-repeat` in a `style` attribute or a `[style]` binding was committed under names native does not read, and now commits what the same declaration in a stylesheet does; a value with a token, a unit other than `px`, `rem` or a percentage, or a negative size is dropped with a warning in development. A `background` in a `style` attribute or a `[style]` binding now takes `linear-gradient(red, blue) center / cover no-repeat` and `linear-gradient(red, blue) green`, which were dropped with a warning. `background: var(--x)`, in a stylesheet or set on an element, used to leave a weaker rule's `background-size`, `background-position` and `background-repeat` in place; it now puts them back at their initial values, or, where the token is a layer with no image such as `center / cover`, places an image a stronger rule declares as the token says. On macOS, `-webkit-font-smoothing` now draws on a `<text-input>`, single-line and multiline, and a `<search-field>`, while they are edited too (but for a secure entry's dots), and `registerViewName` takes `fontSmoothing: true` for a view of a library's that draws it. `-webkit-font-smoothing: var(--x)` used to be dropped with a misleading vendor-prefix warning, and `inherit`, `initial` and `unset` with a warning; a token that is none of its keywords, or such a value set on an element, now leaves the inherited value, as in Chrome, where it used to draw as `auto`. On macOS, `font-family: Menlo` now draws in Menlo, where it drew in SF Mono, and a `<search-field>` draws `monospace` and `ui-monospace` in SF Mono, where it drew the system font; `<code>` on macOS, which the element styles give Menlo, now draws in Menlo as on iOS.
