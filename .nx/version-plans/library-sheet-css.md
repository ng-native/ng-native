In every app's CSS, a `calc()` that adds a token to a percentage, `calc(100% - var(--handle))`, now sizes, places and spaces a box, settled where the box is, where it used to be dropped. The Tailwind `browser` option names the classes that components written for a browser sit under: there a flex container that names no direction is a row, and with it set the whole sheet reads `::before` and `::after` as boxes of their own, `visibility`, a clip to nothing, `overflow-x` and `overflow-y`, and `:checked`, `:indeterminate` and `:enabled` as a browser does.
