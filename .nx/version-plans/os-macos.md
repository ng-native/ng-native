macOS is reported as an OS of its own. The `OS` token from `@ng-native/device` is `'ios' | 'android' | 'macos' | 'web'`, where it used to read `'ios'` on every OS but Android and the web, and a new `DESKTOP` token is `true` on macOS, worked out from `OS`. `isApplePlatform()` from `@ng-native/fabric` is `true` on iOS and macOS. `registerPlatformComponents('macos')` draws with iOS's view names, except `<refresh-control>`, `<input-accessory-view>` and `<full-window-overlay>`, which are plain views on macOS. On macOS, `Dialogs.ask()` uses the iOS prompt, `<section-list>` pins its section headers by default, and `<markdown>` draws code in Menlo, as on iOS. A check an app wrote for iOS can now answer differently on a Mac: `=== 'ios'` is false there, `!== 'android'` is true, and `OS_VERSION`, the macOS major on a Mac, matches macOS 26 where a check meant iOS 26. The `os-comparisons-on-macos` migration notes each one with its file and line; see [Updating an app](https://ng-native.com/guide/updating) for how to run it.
