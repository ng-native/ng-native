The engine can draw a library's `::before` and `::after` boxes: a view first and last in each element a rule gives a `content`, styled by the rules for it, with the words a string `content` writes as its text. Only a library the build names as written for a browser is compiled this way, and nothing names one yet: it is for the upcoming `@ng-native/web-compat` package. Every app's own CSS still drops pseudo-elements with a warning.
