`@ng-native/desktop` connects a dev run on macOS to React Native DevTools through the dev server's inspector proxy (`j` in the Expo CLI, or Developer > Open DevTools), with the console, source-mapped sources, breakpoints and a "Paused in debugger" overlay, and shows JavaScript errors, fatal and logged with `console.error`, in a red box window with Dismiss, Reload and Copy.
