`<ng-icon>` draws the shapes of an outline icon that can be drawn as one, next to each other with one stroke and no fill and under the conditions below, as a single native path, so a lucide icon commits half as many native views and a tabler, feather, iconoir or huge-icons icon a quarter to a third fewer.

Shapes merge only where one path draws them as they were drawn apart, but for the one commit described below: next to each other, with no fill, no opacity, dash or marker, the same paint and not a gradient or pattern, no value from a CSS custom property other than ng-icons' stroke width, no `id` another element points at, path data and points that parse to their end, and no closed shape that is no wider or taller than its stroke at the stroke width the icon draws with. Where two strokes in a colour with any transparency cross, drawn apart the crossing is blended twice, as the web draws it, and drawn as one path it is blended once, which shows as a different shade. So `currentColor` shapes merge only while the icon's colour is opaque as far as `<ng-icon>` knows when it draws them: a colour on its `color` input is known from the commit that sets it, and a stylesheet's from the commit after the one that settles it. In the commit in which a stylesheet colour stops being opaque, the crossings are blended once, and from the next one the shapes are drawn apart: that commit is a new icon's first, where its own stylesheet colour is not opaque and its parent's is, or one that changes the colour of an icon already drawn, as a change of theme can. A stroke written in a colour of its own merges only where that colour is opaque. Every other shape is drawn as before. Across 1,000 lucide icons on the iOS simulator, drawing them takes about 10% less JavaScript time and 20% less main-thread time.

Where two strokes cross, edge pixels blend once rather than twice, and on iOS a stroke edge that sits on a pixel boundary can round to the pixel beside it. Every ng-icons icon the merge changes was compared with its unmerged drawing on iOS and Android, with no shape moved or missing.
