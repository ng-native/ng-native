A CSS transition of a size or a place that is started again before it ends, twice in a row, such as a progress bar stepping its `width`, is now committed where it ends from that third start on where it is eased from JavaScript, as it already was where native plays it as a layout animation. On a host with no layout animation, which includes Android unless the app turns them on, such a bar no longer keeps JavaScript committing on every frame for as long as it moves. Each step is drawn at once, which departs from CSS, where every step would ease.
