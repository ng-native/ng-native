`withWebCompat` and `webCompat()` resolve `@ng-icons/core` to the new `@ng-native/web-compat/ng-icons` entry point, whose `NgIcon` is the one from `@ng-native/icons`, so a library's icons, Spartan UI's helm among them, draw as native shapes. `@ng-icons/core` is an optional peer.
