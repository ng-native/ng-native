A component's host is matched again when a class its own `:has()` names comes or goes, and a `:has()` rule is asked only of a box with the classes and element it names, `:where(.group)` and `tr` among them, and `:has(> )` only of the box right above the change. What comes after a node is asked once a list rather than once an element, so a long list whose items ask `:has(~ .x)` or `:has(+ .x)` restyles in milliseconds where it took seconds. An element no longer keeps a record of the rules it matched once no sheet in play asks for one.
