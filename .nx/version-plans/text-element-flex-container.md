One of HTML's text elements that is a flex container aligning its text, as `<span class="flex items-center justify-center">AH</span>` centres an avatar's initials, places the text as a browser does. It is drawn as a view around a paragraph of the text, where it was a paragraph whose text sat at its top left whatever the alignment. A `<text>` is unchanged, and so is an element that holds more than one run of text. The paragraph the engine makes for text written straight into a view is laid out again when the system text size changes or a face it names is declared later, as any other text is.
